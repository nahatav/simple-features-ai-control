# Simple Features Beat Most AI Control Monitors

Project page for the paper by Shubhrangshu Debsarkar and Valmik Nahata (equal contribution),
NeurIPS 2026 Workshop on Self-Evolving Diversity-Driven Search for Robust AI Systems (EvoRobust).

- Page: https://nahatav.github.io/simple-features-ai-control/
- Paper: https://arxiv.org/abs/2610.41713
- Code: https://github.com/ShubsDS/authorship-not-sabotage
- Data: https://huggingface.co/datasets/vnahata/apps-backdoor-rebuilt-pairs

The site is static. To preview it locally, run `python -m http.server 3000` in this folder and open
http://localhost:3000.

Built on the [Research Project Page Template](https://github.com/ai4co/research-project-page-template),
which is based on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template)
and [Nerfies](https://nerfies.github.io). Like the template, the site is licensed under
